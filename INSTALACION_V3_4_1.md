# Instalación v3.4.1

1. Firebase Console → Firestore → Reglas.
2. Reemplace las reglas por `firestore.rules`.
3. Pulse **Publicar**.
4. En la raíz del repositorio GitHub Pages reemplace:
   - `index.html`
   - `admin.html`
   - `.nojekyll`
5. Commit y push a `main`.
6. Abra GitHub Pages y haga `Ctrl + F5`.

Después, vaya a **Datos → Historial de cortes**.
Los cortes en borrador mostrarán **Eliminar** para Administrador y Jefe de Cartera.
