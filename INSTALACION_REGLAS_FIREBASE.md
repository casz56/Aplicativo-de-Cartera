# Paso obligatorio: reglas Firestore v3.4.0

Antes de utilizar el Editor Operativo:

1. Firebase Console → Firestore → **Reglas**.
2. Reemplace el contenido por `firestore.rules`.
3. Pulse **Publicar**.
4. Luego publique `index.html`, `admin.html` y `.nojekyll` en la raíz de GitHub Pages.

El rol `analista_cartera` puede editar cortes en borrador y cargar información.
No puede publicar el corte oficial. La publicación sigue reservada a `admin` y `jefe_cartera`.
